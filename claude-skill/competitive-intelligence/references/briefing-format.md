# Briefing format

```markdown
# Competitive Intelligence Brief — <date>
> Data: <fictional sample data | user-supplied files | live tools used: ...>

## Executive summary
3–5 sentences, most important finding first.

## High-priority signals
### 1. <title>
| | |
|---|---|
| Competitor / product | PeakTrail · Ridge 32 oz (PT-RIDGE-32) |
| What changed | Listed price decreased 17.9% |
| Previous observation | $39.00 USD on 2026-10-01 (pt-ridge-2026-10-01) |
| New observation | $32.00 USD on 2026-11-01 (pt-ridge-2026-11-01), no promotion label |
| Why it matters | Direct competitor to our $39 Summit 32 oz |
| Supporting evidence | source/snapshot IDs |
| Confidence / uncertainty | Medium — permanence unknown from two observations |
| Recommended next step | Owner + concrete action |

## Medium-priority signals
(same table)

## Customer sentiment
Sample description (records, unique, duplicates excluded), then a table:
Theme statement ("N of the M reviews in our sample mention …") · count · recurring? ·
review IDs · interpretation.

## Lower-priority observations
Low signals and explicit "No alert" decisions with reasons.

## Information requiring verification
Not-comparable pairs, missing data, unverified claims, and open questions (hypotheses
clearly labeled unconfirmed).

## Sources
ID · type · observed/published date · URL or file.
```

Write plainly for a busy owner. Every number comes from the data or from code.
