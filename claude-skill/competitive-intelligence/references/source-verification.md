# Source verification rules

| Requirement | Example |
|---|---|
| Source ID or URL for every observation | `src-pt-ridge-2026-11-01`, review `PT-R04` |
| Observation or publication date | "listed at $32 on 2026-11-01" |
| Price type | current price vs strikethrough/list price vs labeled promotion |
| Sample size for every count | "8 of the 20 reviews in our sample" |
| Reliability of announcements | primary source (company) vs unverified (forum, rumor) |

## Confidence labels
- **High** — direct, comparable, complete observations.
- **Medium** — interpretation (messaging), small samples, permanence unknown.
- **Low** — single or partial observation, unverified source. Put it under
  "Information requiring verification".

## Never
- Cite a source you did not actually read in this conversation.
- Fill gaps with plausible numbers or reviews.
- Treat search-result snippets as verified page content; open the page when possible.
- State a competitor's motive as fact.
